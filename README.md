# Credit Risk EDA Project

## Objective
To analyze loan data and identify key factors affecting credit default risk.
## Dataset
Loan dataset containing customer financial details used to analyze credit risk.

## Tools Used
- Python (Pandas, NumPy)
- Matplotlib, Seaborn

## Steps Performed
- Data cleaning
- Univariate and bivariate analysis
- Data visualization

## Key Insights
- Income and credit amount influence default risk
- Outliers present in financial variables
## Conclusion
This analysis helps identify key risk factors and can support better credit decision-making.
